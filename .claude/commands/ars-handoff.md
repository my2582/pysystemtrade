# /ars-handoff

Create a handoff file before ending a substantive session.

Required output:

`docs/handoff_<YYYYMMDD>_<short_topic>.md`

Include:

1. current objective;
2. files changed;
3. commands run;
4. tests run;
5. unresolved issues;
6. ARS status;
7. next recommended step;
8. assumptions that may become stale.
