# /ars-evidence-pack

Create or update an ARS evidence pack.

Required actions:

1. Read ARS Evidence Pack Standard.
2. Read project profile.
3. Preserve native engine outputs.
4. Create evidence pack under:
   - `ars/evidence_packs/<strategy_id>/<run_id>/`
   or
   - `ars/runs/<YYYY-MM-DD>/<run_id>/`
5. Include:
   - executive summary;
   - hypothesis;
   - data and universe;
   - config;
   - performance summary;
   - statistical inference;
   - robustness checks;
   - reproducibility metadata;
   - AI-agent involvement;
   - limitations;
   - ARS verdict.
6. Do not invent missing metrics. Mark missing items explicitly.
